# Project Status
Use this plugin when a user asks for a project's current status.

1. Ask for a project ID if it is not provided.
2. Call `get_project_status` with that ID.
3. Report the returned project ID, workspace, and status. Cite the returned source.
4. If the tool fails or requires approval, explain that and do not invent a result.

The starter returns fixture data. Replace the implementation with a real service
before presenting it as live project information.
